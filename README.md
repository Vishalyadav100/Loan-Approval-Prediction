# 🏦 Loan Approval Prediction Dashboard

A Machine Learning web application built with **Python** and **Streamlit** that predicts whether a loan application will be approved or rejected based on applicant information.

---

## 📌 Project Overview

The Loan Approval Prediction Dashboard helps banks and financial institutions automate loan approval decisions using Machine Learning algorithms.

Users can:

- 📂 Analyze the dataset
- 🧹 Perform data preprocessing
- 🤖 Train multiple ML models
- 📊 Compare model performance
- 🔮 Predict loan approval
- 📈 Visualize results
- 📥 Download trained models and reports

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/your-username/Loan-Approval-Prediction.git
```

Go to project folder

```bash
cd Loan-Approval-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
